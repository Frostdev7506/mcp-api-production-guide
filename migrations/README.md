Apply numbered SQL files through `npm run migrate` with `MIGRATION_DATABASE_URL` supplied by the deployment secret store. The role must have DDL permissions; the runtime role must not. Applied checksums are immutable and migration application is serialized in a database transaction. Create a new numbered migration to change the schema. Migrations do not create demo users or seed sample tickets.

The local first-volume bootstrap applies and records 001, then separately loads disposable sample data. An older existing database must be audited and explicitly baselined by its owner before using this journal; do not mark a migration applied just to silence an error. Production must create the restricted `support_app` role and database before applying 001, and manage passwords outside SQL files.
